My first WordPress plugin, step by step

18 Sep 2026 · A tiny plugin with a shortcode and a settings page. The whole thing fits in one file.

My first plugin did one small thing: show a notice box anywhere with a shortcode. Here's how it works.

The plugin header

<?php
/**
 * Plugin Name: TV Notice
 * Version: 1.0
 */
defined( 'ABSPATH' ) || exit;

The last line stops direct access to the file.

The shortcode

add_shortcode( 'notice', function () {
  $text = get_option( 'tv_notice_text', 'Hello' );
  return '<div class="tv-notice">' . esc_html( $text ) . '</div>';
} );

Always escape output. esc_html stops broken HTML and script injection.

A settings page

I used the Settings API. It handles saving and security for you.

add_action( 'admin_init', function () {
  register_setting( 'tv_notice', 'tv_notice_text', [
    'sanitize_callback' => 'sanitize_text_field',
  ] );
} );

Then add a page under Settings with add_options_page and print the form.

What I'd tell a beginner

  • Start with one file.
  • Learn actions and filters first.
  • Sanitise input. Escape output. Every time.
