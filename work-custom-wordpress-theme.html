Custom WordPress theme

WordPress · PHP A theme built from a blank folder on the template hierarchy.

The goal

Build a WordPress theme with no starter theme and no page builder.

What I did

  • Started from a blank folder with style.css and index.php.
  • Added templates for pages, single posts and archives.
  • Registered a custom post type and menus.
  • Added widget areas in the sidebar and footer.
  • Loaded CSS and JS with wp_enqueue_scripts, not hard-coded tags.
add_action( 'wp_enqueue_scripts', function () {
  wp_enqueue_style( 'theme', get_stylesheet_uri(), [], '1.0' );
} );

What I learned

The template hierarchy decides which file loads. Once that clicks, WordPress stops feeling like magic.
