Northline Menswear – Shopify store on Ella

Shopify · Liquid · Live store A full men's wear store on the Ella theme. 28 products, India-only checkout and custom Liquid pages.

Live store: northline-menswear-mir9ttrn.myshopify.com
It is a Shopify development store, so it is password protected. Ask me for the password and I'll send it over.

The goal

Build a complete men's wear store on the paid Ella theme. From an empty store to a working checkout.

Northline is a made-up brand. Product photos are free Unsplash images.

What I built

  • 28 products with 243 variants, imported from one CSV.
  • 10 collections driven by product tags: shirts, jeans, jackets, ethnic wear, best sellers and more.
  • Homepage built from Ella sections: hero, collection tiles, best sellers, shop-the-look and a gallery.
  • Main menu, mobile menu and footer menus.
  • About, FAQ, Shipping & Returns and Contact pages.
  • Prices in ₹ INR. Checkout limited to India and Indian states.
  • Shipping rates: ₹99 standard, free above ₹1,999, ₹199 express. Cash on Delivery option.
  • Test orders placed end to end, from add to cart to order confirmation.

Custom Liquid

The info pages share one custom section. It picks a layout from the page handle, so no page needs a special template.

{%- case page.handle -%}
  {%- when 'about-us' -%}  {% comment %} hero, story, values {% endcomment %}
  {%- when 'faq' -%}       {% comment %} grouped accordions {% endcomment %}
  {%- when 'shipping-returns' -%}
  {%- else -%}
    {{ page.content }}
{%- endcase -%}

The FAQ uses plain <details> tags. No JavaScript needed to open and close answers.

Problems I fixed

  • Removed Ella demo content: countdown timers, fake popups and demo labels.
  • Made every product image in a row the same size with one fixed ratio.
  • Darkened the hero photo so the white heading reads clearly.
  • Moved shop-the-look hotspots so each dot sits on the product it opens.
  • Stopped the footer showing through the page on scroll.
  • Checked every page at phone and desktop widths.

What I learned

Collections come first. Filters, menus and the homepage all depend on them.

Edit theme JSON in small steps and check the live page after each one. A theme's global styles can override your CSS in ways you only see in the browser.
