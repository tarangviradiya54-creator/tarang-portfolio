Lumé Skin

WordPress · WooCommerce A skincare store with a custom child theme and a skin quiz.

Live store: lumeskin.infinityfreeapp.com
Open to everyone. Checkout is in demo mode, so no payment is taken.

The goal

Build a full WooCommerce store for a clean skincare brand. Local build first, then live on real hosting.

Lumé is a made-up brand. Photos are free Unsplash images. I relabelled the bottles with a small Python script.

Stack

WordPress, WooCommerce, Kadence theme with my own child theme, Rank Math, WP Super Cache. Built in LocalWP.

Custom code I wrote

  • Skin quiz. Four questions. AJAX returns a routine and adds it to the cart in one click.
  • Ingredient glossary. A custom post type linked to products. Each ingredient page lists the products that use it.
  • Product fields. Custom meta boxes for key actives, skin type and how to use, shown on the product page.
  • Before/after slider. A shortcode with a drag handle, plain JavaScript.
  • Homepage sections. Marquee, shop-by-concern, reviews and newsletter as shortcodes.
  • Cookie banner. My own, cache-safe, instead of a heavy plugin.

Store setup

  • 22 products and 4 bundles at 15% off.
  • USD and INR prices with a currency switcher.
  • Shipping zones for the US, UK, EU, Canada/Australia and India. Free over $40 to India.
  • Sales tax rules, including 18% GST for India.
  • Test orders placed end to end.

SEO and speed

  • Rank Math titles, meta descriptions and schema for products, the organisation and articles.
  • XML sitemaps with 71 URLs, all returning 200.
  • Page caching took the homepage from 1.3 s to under 0.2 s locally.

Going live

I moved the site from LocalWP to InfinityFree myself. Exported the database, swapped the local URLs for the live ones, then imported it on the host with the theme and images.

After the move, inner pages returned 404. The server's .htaccess had no WordPress rewrite rules. I added them and cleared out an old cache plugin's leftover files.

Free hosting is slower than paid. For a demo store, that's fine.
