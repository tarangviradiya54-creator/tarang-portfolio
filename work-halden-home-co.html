Halden Home Co.

Shopify · Liquid A US home essentials store on the Dawn theme, with five custom Liquid sections.

Live store: halden-home-co.myshopify.com
It is a Shopify development store, so it is password protected. Ask me for the password and I'll send it over.

The goal

Build a premium home essentials store for US shoppers on Shopify's free Dawn theme, then go past the theme settings with my own sections.

Halden is a made-up brand. Product and room photos are free Unsplash images.

Custom sections I wrote

  • Shop by room. Collection cards with the room name over the photo and a live product count.
  • Bundle offer. Liquid adds up the three prices and shows the bundle price. One button adds all three to the cart with the Cart API.
  • Home essentials finder. Two questions, room and need, then it points you to the right collection. Plain JavaScript as a custom element.
  • Product comparison. A table comparing three towels on material, size, care and best use.
  • Benefits strip. Shipping, returns and materials with inline SVG icons, reused on the home, product and contact pages.

Store setup

  • 54 products with 94 variants, imported from one CSV that a small Python script generates, photos included.
  • 12 collections driven by product tags: four rooms, storage, cleaning, best sellers, new arrivals, sale and three edits.
  • Mega menu, footer menus, and About, FAQ, Shipping & Returns, Contact and Compare pages.
  • Refund, terms, shipping and contact policies.
  • A BUNDLE15 code that takes 15% off only when all three bundle items are in the cart.
  • Test order placed end to end with test payments. $118.00 became $100.30 with the code.

How I worked

I edited the theme files locally and used Shopify CLI to preview changes live and push them to the store. Theme Check reports zero errors. Every page was checked at phone width for sideways scrolling.

A bug I fixed

The finder showed all six answers before anyone clicked. My CSS gave each result display: grid, which beat the browser's hidden attribute. One rule fixed it:

.he-finder__result[hidden] { display: none; }
