Shopify Liquid basics for beginners

10 Sep 2026 · Objects, tags and filters in Liquid, explained with small examples you can try today.

Liquid is the template language behind every Shopify theme. It looks odd at first. It's simple once you know the three parts.

Objects

Objects output data. They use double curly braces.

{{ product.title }}
{{ product.price | money }}

Tags

Tags add logic. They use curly braces with percent signs.

{% if product.available %}
  In stock
{% else %}
  Sold out
{% endif %}

Filters

Filters change output. They come after a pipe.

{{ product.title | upcase }}
{{ 'hero.jpg' | asset_url }}

Loops

{% for product in collection.products limit: 4 %}
  <h3>{{ product.title }}</h3>
{% endfor %}

Sections and schema

Modern themes are built from sections. Each section has a schema block. That schema creates the settings you see in the theme editor.

Add a setting in the schema, read it with section.settings, and store owners can change it without touching code.

Where to practise

Duplicate your theme and edit a small section. Change a heading. Add a setting. Break it, then fix it.
