Elementor landing page

WordPress · Elementor A landing page built in Elementor, with custom CSS where needed.

The goal

Build a landing page quickly in Elementor that still loads fast on mobile.

What I did

  • Hero, benefits, testimonials and a call-to-action section.
  • Global colours and fonts, so changes happen in one place.
  • Custom CSS for the spacing Elementor couldn't handle.
  • Checked every section on phone and tablet sizes.

What I learned

Page builders are fast for layout. A few lines of CSS fix the last 10%.

Keep widgets to the ones you need. Every extra one adds weight.
