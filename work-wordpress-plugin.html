Small WordPress plugin

WordPress · PHP Hooks, a shortcode and an admin settings page. No bloat.

The goal

Replace a heavy plugin with a small one that does one job well.

What I did

  • Wrote a single-file plugin with a proper header.
  • Added a shortcode that outputs a notice box.
  • Built an admin settings page with the Settings API.
  • Escaped output and sanitised input.
add_shortcode( 'notice', function ( $atts ) {
  $text = get_option( 'tv_notice_text', 'Hello' );
  return '<div class="tv-notice">' . esc_html( $text ) . '</div>';
} );

What I learned

Hooks are the whole game. Actions do things. Filters change things.
