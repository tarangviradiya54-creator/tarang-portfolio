Building a WordPress theme from scratch

14 Sep 2026 · The files you need, the template hierarchy, and how to load CSS and JS the right way.

Starter themes are great. But building one from zero once teaches you how WordPress really works.

The two files you need

A theme only needs style.css with a header comment and an index.php.

/*
Theme Name: My Theme
Version: 1.0
*/

The template hierarchy

WordPress looks for the most specific template first. For a single post it tries single-post.php, then single.php, then index.php.

Add files only when you need a different layout.

functions.php

This is where you turn on features and load assets.

add_action( 'after_setup_theme', function () {
  add_theme_support( 'title-tag' );
  add_theme_support( 'post-thumbnails' );
  register_nav_menus( [ 'primary' => 'Primary menu' ] );
} );

Load CSS and JS properly

Use wp_enqueue_style and wp_enqueue_script. Never hard-code link tags in the header. Plugins depend on this.

header.php and footer.php

Split the shared parts out. Call wp_head() and wp_footer(). Many plugins break without them.
